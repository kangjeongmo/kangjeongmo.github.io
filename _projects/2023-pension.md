## 프로젝트 개요

2020년부터 2023년까지 약 **50여 개의 펜션 홈페이지를 제작 및 유지보수**하였습니다.  
디자이너 1명, 개발자 1명으로 구성된 2인 체제로 운영되었으며,  
저는 전체 기여도 50% 중 **퍼블리싱 100%**를 담당했습니다.

각 홈페이지는 평균 1~2주 제작 기간으로 진행되었으며,  
펜션별 브랜드 이미지·촬영 사진·편의시설·객실 정보를 기반으로  
개별 맞춤형 UI를 구현했습니다.

## 핵심 기능

- 펜션 소개 페이지  
- 객실 정보 및 상세 페이지  
- 종합 예약안내 페이지  
- 주변 여행지 소개  
- 스페셜(바비큐, 스파 등) 소개  
- 게시판(공지사항/문의)  
- 반응형 퍼블리싱  

## 기술 구현

### 프론트엔드 / 퍼블리싱

- **HTML/CSS/JavaScript 퍼블리싱 100% 담당**  
- jQuery 기반 인터랙션(메뉴, 슬라이드, 모달 등)  
- 반응형 레이아웃 구성(PC/모바일)  
- 펜션 브랜드·디자인 컨셉에 맞춘 UI 커스터마이징  
- 객실별 요금, 옵션, 사진 갤러리 퍼블리싱  

### 백엔드 / 시스템 연동

- PHP 7.4 + MySQL 기반 데이터 구조에 맞춰 프론트엔드 적용  
- CodeIgniter 4 또는 그누보드 5 기반으로 페이지 구성  
- 게시판, 문의 폼 등 CMS 구조에 맞춘 퍼블리싱 연동  
- 관리자 페이지에서 등록 데이터가 UI에 일관되게 표시되도록 구조화  

### 디자인 협업

- Photoshop으로 제공된 디자인을 웹 표준에 맞춰 완벽하게 퍼블리싱  
- 촬영된 펜션 사진을 갤러리/슬라이더로 구성해 시각적 완성도 강화  
- 디자이너와 협업하여 각 펜션 브랜드 이미지에 맞춘 스타일 적용  

## 성과

- 50여 개의 펜션 홈페이지를 안정적으로 제작 및 운영  
- 평균 제작 기간 1~2주로 빠른 속도의 반복 프로젝트 수행  
- 예약 안내·객실·여행지·스페셜 등 펜션 정보 전달을 최적화  
- 디자이너와 효율적인 협업 프로세스 구축  
- CodeIgniter/그누보드 기반으로 한 관리자 사용성 개선  

## 기술적 도전과 해결

각 펜션마다 사진·정보·레이아웃이 모두 다르기 때문에  
효율적인 퍼블리싱 프로세스를 구축하는 것이 가장 큰 도전이었습니다.

이를 해결하기 위해:

- 반복적으로 사용되는 UI 컴포넌트(객실 리스트, 여행지 리스트 등)를  
  **퍼블리싱 템플릿화**  
- 공통 CSS 구조를 정의해 스타일 가이드 확립  
- 관리자에서 입력된 데이터가 반영되는 동적 페이지의 구조를  
  펜션별로 쉽게 재사용할 수 있도록 분리 설계  
- 유지보수 시 공통 영역과 개별 영역을 명확히 구분하여  
  수정 속도 및 안정성을 확보  

그 결과, 단기간에 여러 펜션 홈페이지를 제작하면서도  
일관된 품질을 유지하는 효율적인 개발 프로세스를 구축했습니다.
