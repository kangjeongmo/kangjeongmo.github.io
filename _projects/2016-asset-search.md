## 프로젝트 개요

애니메이션 제작 과정에서 필요한  
수많은 에셋(캐릭터, 배경, 소품 등)을 빠르게 검색하고 관리할 수 있는  
**에셋 검색 프로그램(Asset Search System)**을 단독 개발했습니다.

공정관리 시스템과 에셋 버전관리 툴에서 활용되는 데이터를 통합하여  
애니메이션 아티스트와 PM이 필요한 정보를 즉시 찾을 수 있도록  
효율적인 검색 환경을 구축했습니다.

## 핵심 기능

- 서버 내 에셋 파일 자동 수집 및 DB 업데이트 (crontab, 매일 오전 6시)  
- 에셋 검색(파일명, 태그, 공정별 필터 지원)  
- 파일 서버 경로 표시  
- 파일 다운로드 기능  
- 이미지 프리뷰 / 상세 보기  
- 태그 기능(추가, 삭제, 검색)  
- Maya / 3ds Max 파일 유형 구분 표시  
- 애니메이션 공정 상태 표시 (디자인, 모델링, 리깅 등)

## 기술 구현

### 데이터 수집 자동화

- 서버의 에셋 파일을 주기적으로 스캔하여  
  폴더 구조 및 메타데이터를 매일 DB에 최신 상태로 반영  
- Linux `crontab`을 활용해 **매일 오전 6시에 자동 동기화 작업 수행**  
- 파일 확장자, 경로, 수정일, 공정 정보 등을 정규화하여 저장  

### 백엔드

- Nginx + PHP 5.6 환경 구성  
- CodeIgniter 3 기반 MVC 구조로 개발  
- 에셋 검색 쿼리 최적화로 대량 데이터도 빠르게 조회 가능  
- MySQL 기반 테이블 설계 및 검색용 인덱스 적용  

### 프론트엔드

- jQuery 기반 인터랙션 구현  
- Bootstrap 3 기반 반응형 UI 구축  
- 이미지 목록·그리드 방식의 에셋 프리뷰 제공  
- 공정별 태그 및 필터 적용 UI 구성  

## 성과

- 기존에는 에셋 위치를 사람이 직접 찾아야 했던 작업을 시스템화하여  
  **작업 조회 속도 대폭 향상**  
- 태그 기반 검색과 공정별 필터로 아티스트의 작업 효율 증가  
- 파일 관리 혼선을 줄이고, 애니메이션 파이프라인 전체의  
  **에셋 접근성이 크게 향상**  
- 모델러, 리거, 애니메이터 등 여러 팀 간 작업 공유가 원활해짐

## 기술적 도전과 해결

에셋 파일의 종류가 2D/3D/이미지/프로젝트 파일 등 다양하고  
폴더 구조 또한 프로젝트별로 다르게 운영되어  
일관된 DB 구조를 만드는 것이 주요 도전 과제였습니다.

이를 해결하기 위해:

- 파일 확장자 기반의 카테고리 규칙 생성  
- Maya / 3ds Max 등 DCC 툴별 처리 로직 분리  
- 태그 시스템을 도입하여 검색 정확도 향상  
- 데이터 동기화 로직을 최적화하여  
  대규모 파일 구조도 빠르게 스캔·저장 가능하도록 구조 개선  

이를 통해 **애니메이션 제작 파이프라인 전체에서  
에셋 검색·조회 시간을 획기적으로 단축**할 수 있었습니다.
