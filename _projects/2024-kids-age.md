## 프로젝트 개요

조카의 나이를 정확하게 계산하고, 생일 및 성장 정보를 편하게 관리하기 위해 개발한  
**개인용 iOS 유틸리티 앱**입니다.  
나이 계산 정확도, 정렬 UX, 삭제 복구 기능 등 실사용자 경험을 중심으로 설계했으며  
기획부터 디자인·개발·배포까지 **전 과정 100% 단독 개발**했습니다.

SwiftData와 SwiftUI 기반의 최신 아키텍처로 제작되었으며  
한국어·영어·일본어 3개국어를 완벽하게 지원합니다.

---

## 주요 기능

### 1) 다중 정렬 리스트 관리
- 드래그 앤 드롭 기반 **수동 정렬**
- **이름순 / 나이순 / 생일순** 자동 정렬
- 입력 즉시 반영되는 **실시간 검색 기능**

### 2) 정밀한 나이 계산
- `"12살 (9개월 15일)"` 형태의 **세밀한 나이 표현**
- 오늘 생일인 경우 자동으로 **🎂 표시**
- **7일 이내 생일은 D-day 알림** 제공

### 3) 소프트 삭제 시스템
- 사진 앱처럼 **최근 삭제된 항목 보관함** 제공
- 30일 후 자동 삭제
- **남은 일수(D-day) 카운트다운** 표시
- 삭제 취소(복구) 지원

### 4) 메모 기능
- 텍스트 200자 제한
- 실시간 글자수 카운터 UI
- 메모가 있는 항목은 리스트에서 **📝 아이콘 표시**

### 5) 3개국어 지원
- 한국어 / 영어 / 일본어 완벽 지원  
- 총 **1,598줄 규모의 로컬라이제이션 파일**
- 단순 번역이 아닌 **문맥 기반 UI/UX 현지화**

## 기술 구현

### 아키텍처
- **SwiftUI + SwiftData 기반 최신 구조 적용**
- MVVM 패턴으로 뷰와 로직 명확히 분리
- NavigationStack(iOS 16+)으로 화면 이동 구조 설계

### 상태 관리
- `@Query` → SwiftData 기반 자동 데이터 페칭  
- `@Bindable` → 양방향 데이터 바인딩  
- `@State` → UI 레벨의 경량 상태 관리  

### 데이터 모델
- `@Model` 매크로로 **자동 영속성 지원**
- `Predicate` 기반 **타입 안전(Type-safe)** 쿼리
- 소프트 삭제(삭제일 저장, 30일 카운트다운) 내장 로직
- 정렬/검색 기능을 고려한 인덱스 기반 데이터 구조

### SwiftData 활용
- SwiftData가 제공하는 경량 영속성 + 쿼리 기능을 적극 활용  
- D-day 계산, 생일 이벤트, 정렬 등의 데이터 흐름을  
  성능 저하 없이 처리할 수 있도록 구조화
