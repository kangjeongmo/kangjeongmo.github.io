## 📱 프로젝트 개요

Figma·Photoshop 디자인을 기반으로  
**2개의 랜딩페이지와 1개의 PDF 백서 다운로드 페이지**를 제작한 웹퍼블리싱 프로젝트입니다.  

전체 페이지 퍼블리싱 및 구현을 **100% 단독 개발**로 진행했으며,  
디자인 반영 정확도·반응형 레이아웃·모던 UI 스타일을 우선하여 개발했습니다.

---

## ⭐ 주요 기능

### 1) 랜딩페이지 제작 (2개)
- Figma·Photoshop 디자인 1:1 퍼블리싱  
- 반응형 웹 디자인(PC/모바일)  
- CSS 애니메이션·스크롤 인터랙션 구성  
- SEO 친화적 마크업 적용  
- 이미지 최적화로 로딩 속도 개선  

### 2) PDF 백서 다운로드 페이지
- PHP 기반 PDF 다운로드 처리  
- 사용자 행동 분석을 위한 단순 이벤트 로깅  
- 브라우저/기기 호환성 고려  
- 다운로드 버튼 UI 커스터마이징  
- 모바일 최적화  

### 3) 기본 기능 및 UI 구성
- 섹션 · 소개 · 특징 · CTA 구성  
- UX 중심 인터랙션  
- 폼 전송 또는 외부 링크 연결  
- 웹 표준·웹 접근성 기본 준수  

---

## 🛠 핵심 기술 구현

### 1) 웹퍼블리싱
- HTML 시멘틱 태그 기반 구조  
- SCSS 없이 Pure CSS로 반응형 구현  
- Flexbox·Grid 기반 레이아웃 적용  
- UI 애니메이션 처리  

### 2) 디자인 매칭
- Photoshop·Figma 디자인을 **레티나 해상도 기준 1:1 정확도**로 퍼블리싱  
- 이미지 자산 최적화  
- 색상, 타이포그래피, 간격(Spacing) 규칙 정확히 반영  

### 3) 다운로드 페이지(PHP)
- PHP 기반 파일 다운로드 처리(파일헤더 설정)
