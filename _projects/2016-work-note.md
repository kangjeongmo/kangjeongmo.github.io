## 프로젝트 개요

회사 내 제작팀(디자인, 모델링, 리깅, 애니메이션 등)의  
**일일 업무 관리 및 휴가 관리 업무를 시스템화**하기 위해  
업무일지 프로그램(Daily Worklog System)을 단독 개발했습니다.

이전에는 파일 또는 구두로 공유되던  
일일 업무 기록, 작업량 집계, 휴가 신청 내역 등을  
모두 웹 기반 시스템에서 관리할 수 있도록 개선했습니다.

기획부터 DB 설계, 프론트엔드·백엔드 개발까지  
전체 개발 과정을 1인 체제로 수행했습니다.

## 핵심 기능

- 부서별 일일 업무일지 작성  
  - 제작관리 / 디자인 / 모델링 / 리깅 / 애니메이션 / 라이팅  
- 개인별 작업량 관리  
- 휴가 관리 기능(연차, 반차 등록 및 기록)  
- 관리자용 통계 대시보드  
  - 부서별 작업량  
  - 개인별 작업량  
  - 기간별 조회  
- Excel Export 기능  
- 검색/필터 기반 업무 조회  

## 기술 구현

### 백엔드

- CentOS + Nginx 기반 서버 환경 구축  
- CodeIgniter 3 기반 MVC 아키텍처로 기능 단위 모듈 설계  
- MySQL 5.4로 부서/개인/작업량/휴가 관련 테이블 구조 설계  
- REST 스타일 API 구축으로 AngularJS 프론트엔드와 데이터 통신  

### 프론트엔드

- AngularJS 1.4.9 기반 SPA 형태로 UI 구현  
- jQuery 2.2.2로 보조 인터랙션 구성  
- Bootstrap 3로 반응형 UI 구성  
- 실시간 필터링, 기간 검색 등 데이터 기반 화면 구현  
- Excel Export UI 및 다운로드 기능 제공  

### 운영 및 관리 기능

- 부서별/개인별 대시보드로 작업 현황 시각화  
- 휴가 신청 이력 관리 및 관리자 승인 기능  
- 기간별/사용자별 통계 조회  
- 정산 업무 및 프로젝트 일정 관리에 활용 가능  

## 성과

- 일일 업무 보고 및 휴가 관리가 시스템화되어  
  **전 부서의 커뮤니케이션 효율이 증가**  
- 작업량을 시각적으로 확인할 수 있어  
  PM의 일정 관리 및 리소스 배분이 용이해짐  
- Excel Export 기능을 통해  
  보고서 작성 시간 절감  
- 업무 기록이 데이터베이스화되면서  
  장기적 제작 효율 분석에 활용 가능  
- 업무 누락, 휴가 기록 오류 등의 문제가 크게 감소  

## 기술적 도전과 해결

부서마다 업무 형태가 달라서  
업무일지를 단일 구조로 처리하기가 쉽지 않았습니다.

이를 해결하기 위해:

- 공통 필드 + 부서별 확장 필드 구조로 DB를 설계  
- AngularJS 기반으로 입력 UI를 동적으로 변경  
- 데이터 필터링, 기간 검색 등의 기능을 모듈화하여  
  재사용성과 유지보수성을 강화  

이로 인해 다양한 유형의 부서 업무를  
하나의 통합된 시스템에서 일관성 있게 관리할 수 있었습니다.
