## 프로젝트 개요

애니메이션 제작 파이프라인에서 사용되는  
**에셋(Asset) 버전관리 프로그램**을 개발했습니다.  
Maya 기반 작업자(모델러, 리거, 애니메이터 등)가  
파일을 쉽고 일관성 있게 관리하고 버전을 추적할 수 있도록  
데스크톱 기반의 툴 형태로 제공했습니다.

UI/UX 설계부터 구현, API 연동까지 전체 프로세스를 주도적으로 담당했으며,  
프로그램 구조 설계와 주요 기능 구현을 포함해 **80%의 기여도**로 진행했습니다.

## 핵심 기능

- 에셋 리스트 트리(Asset Tree) 구조 제공  
- Maya 파일 서버 데이터 연동  
- Open / Import / Reference 기능 지원  
- Maya 씬 저장(Save) 및 버전 자동 관리  
- 파일 프리뷰, 스크린샷 생성  
- 버전 메모 작성 기능  
- 작업 효율을 높이는 간단한 자동화 기능 포함  

## 기술 구현

### 데스크톱 애플리케이션
- Python 2.7 기반 개발  
- Qt + PySide로 **네이티브 데스크톱 UI** 구성  
- Asset Tree UI를 직접 구성하여 폴더/파일/버전 구조 시각화  

### Maya 파이프라인 연동
- Maya API를 활용한 Open / Import / Reference 기능 구현  
- 알맞은 Pipeline Path 규칙에 따라 자동으로 저장 경로 생성  
- Maya 내부 명령과 외부 서버 파일을 자연스럽게 연결  
- 작업자가 Maya에서 바로 파일 프리뷰/스크린샷 캡처 가능  

### 버전 관리 로직
- 파일 이름 규칙 기반의 버전 넘버 자동 증가  
- Previous Version / Latest Version 조회  
- 버전 히스토리와 메모 기능으로 작업 흐름 추적  

## 성과

- 아티스트들이 파일/버전/경로 문제로 인해 발생하던  
  작업 중단 및 파일 충돌을 대폭 감소  
- 수작업으로 하던 버전 관리를 자동화하여  
  **작업 속도 및 정확성 향상**  
- Asset, Shot, Scene 파일을 표준화된 형태로 관리하게 되어  
  프로젝트 규모가 커져도 혼선 없이 작업 가능  
- 최종적으로 애니메이션 제작 전체 파이프라인의 안정성 확보에 기여  

## 기술적 도전과 해결

Maya 내부 파일 구조와 외부 서버 파일 시스템을  
일관성 있게 연결하는 것이 가장 큰 과제였습니다.

이를 해결하기 위해:

- Maya 명령어(cmds) 및 API를 활용해  
  Open/Import/Reference 기능을 직접 재구현  
- 파일 경로 규칙을 통일하고 Validation 로직을 추가하여  
  아티스트 실수로 인한 파일 파손/덮어쓰기 최소화  
- Python + Qt 기반의 데스크톱 UI에서  
  대규모 Asset 트리도 빠르게 로딩되도록 구조 최적화  

이로 인해 Maya 기반 제작 환경에서  
안정적이고 반복 가능한 버전 관리가 가능해졌습니다.
