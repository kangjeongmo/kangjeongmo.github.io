## 프로젝트 개요

애니메이션 제작 공정을 통합적으로 관리하는  
**공정관리 시스템(Production Pipeline Management System)**을 개발했습니다.  
TV 애니메이션 제작 과정에서 발생하는 다양한  
업무 흐름을 체계적으로 관리할 수 있도록 설계하여 **제작 효율을 크게 향상**했습니다.

프로젝트 기간 동안 기획부터 DB 설계, 프론트엔드·백엔드 개발까지  
모든 개발 과정을 수행했습니다.

## 핵심 기능

- 프로젝트(Series/Season/Episode) 관리  
- Asset 관리(캐릭터, 배경, 소품 등)  
- Shot 관리(컷별 상태 및 작업 현황 추적)  
- 작업 리스트·작업자별 업무 현황  
- 컨펌 리스트 및 승인 프로세스 관리  
- 알림(Notification) 기능  
- 전체 제작 워크플로우 모니터링  

## 기술 구현

### 시스템 구조 및 백엔드
- CentOS 기반 서버 환경 구축  
- Nginx + PHP 5.6 조합으로 경량화된 운영 구조 구성  
- CodeIgniter 3 기반 MVC 아키텍처로 유지보수성 확보  
- MySQL 5.4로 프로젝트·에셋·샷·사용자·작업 내역 데이터베이스 설계  
- RESTful 형태의 데이터 처리 로직 구현  

### 프론트엔드
- jQuery 2.2.2 기반 인터랙션 구현  
- Bootstrap 3를 활용한 반응형 UI 구축  
- 공정 단계별 데이터 시각화 및 상태 표시 UI 구성  

### 운영 및 워크플로우 관리
- 제작 단계별 상태 변경, 작업자 할당, 컨펌 기록 저장  
- 공정별 병목 지점을 빠르게 파악할 수 있도록 데이터 구조 최적화  
- 각 팀(원화팀, 배경팀, 모델링팀, 애니메이션팀 등)의 작업 흐름을 하나의 시스템에서 관리  

## 성과

- 수작업·엑셀 기반으로 운영되던 워크플로우를 시스템화하여  
  **제작 효율이 크게 향상**  
- 샷/에셋/작업 현황을 실시간으로 조회 가능해 팀 간 커뮤니케이션 속도 증가  
- 승인(컨펌) 프로세스가 체계화되어 **작업 지연 및 누락 감소**  
- 공정 상태를 한눈에 파악할 수 있어 PM의 프로젝트 관리 부담 감소  

## 기술적 도전과 해결

애니메이션 제작 특성상 샷/에셋/작업자 간 관계가 매우 복잡하여  
데이터 모델 설계가 가장 큰 도전이었습니다.

이를 해결하기 위해:

- **Shot, Asset, Task** 엔티티 간 관계를 정규화하여 체계적으로 재설계  
- 상태값(State)과 히스토리(History)를 별도 테이블로 관리하여  
  공정 변경 추적이 가능하도록 구조화  
- 담당자 변경, 컨펌 기록, 작업 상태 변화 등을 모두 기록함으로써  
  추후 문제 발생 시 원인 파악이 가능하도록 함

이러한 구조 덕분에 대규모 애니메이션 프로젝트에서도  
지속적으로 안정적으로 활용될 수 있는 시스템을 완성했습니다.
