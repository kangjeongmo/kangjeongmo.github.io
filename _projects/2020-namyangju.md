## 프로젝트 개요

남양주 지역의 숙박업소 정보를 통합 제공하고,  
협회 소개·관광지 안내·커뮤니티 기능 등을 웹에서 편리하게 이용할 수 있도록  
**남양주민박협회 공식 홈페이지**를 개발한 프로젝트입니다.

기획 1명, 디자이너 1명, 백엔드 개발자 1명, 프론트엔드 개발자 1명으로 구성된  
4인 팀 프로젝트였으며, 저는 **React 기반 프론트엔드 개발을 담당했습니다.**

React 컴포넌트 구조 설계, UI 구현, API 연동 등  
사용자 인터페이스 전반을 개발하며 프로젝트에 25% 기여했습니다.

## 핵심 기능

- 남양주 지역 펜션 / 민박 정보 안내  
- 협회 소개 페이지  
- 지역 관광지 소개  
- 커뮤니티 게시판  
- 반응형 UI 구성  

## 기술 구현

### 프론트엔드 (담당 영역)

- React 기반 화면 컴포넌트 구조 설계  
- 지역 정보(펜션, 관광지 등)를 표시하는 리스트/상세 페이지 구현  
- Axios를 통한 API 연동  
- React Router 기반 라우팅 구성  
- 반응형 웹 디자인 적용  
- 카드형 UI, 목록형 UI 등을 페이지별 스타일링  
- 사용자 입력 폼 및 커뮤니티 화면 구성  

### 백엔드 및 인프라 (팀 협업 영역)

- Node.js 기반 API 서버 구축 (백엔드 개발자 담당)  
- MySQL 데이터베이스 설계  
- AWS 환경에서 배포 및 운영 구성  

## 성과

- 지역 숙박업 정보·관광지 정보를 한 플랫폼에서 조회 가능하도록 단일화  
- React 기반 UI 구성으로 사용자 경험(UX) 향상  
- 협회 회원 및 방문객 모두 쉽게 사용할 수 있는 정보 구조 완성  
- 프론트엔드와 백엔드 간 협업으로 안정적인 API 기반 구조 구축  

## 기술적 도전과 해결

남양주 지역의 다양한 펜션·관광 데이터가  
분류·형식 면에서 일관적이지 않아 UI 구조 설계가 어려웠습니다.

이를 해결하기 위해:

- 리스트/카테고리 구조를 React 컴포넌트로 **모듈화**  
- 데이터 타입이 다르더라도 동일 UI로 표시될 수 있도록  
  **공통 데이터 인터페이스 정의**  
- API 규격을 백엔드 개발자와 논의하여 구조를 통일  

그 결과, 여러 유형의 지역 정보를 효율적으로 보여주는  
일관된 UI/UX를 구현할 수 있었습니다.
