## 프로젝트 개요

**기획 문서를 기반으로** 기업 소개용 홈페이지를 구축한 프로젝트입니다.  
브랜드 소개, 프로젝트 포트폴리오, 팀 구성, 채용 정보 등  
기획서에 명시된 콘텐츠 구조와 사용자 흐름을 충실히 반영하여 설계·개발을 진행했습니다.

WordPress 환경에서 **Elementor 페이지 빌더**를 활용해  
디자인 커스터마이징과 페이지 배치를 효율적으로 구현했습니다.  
또한 AWS Lightsail을 사용하여 안정적이고 비용 효율적인 서버 환경을 구축했습니다.

## 핵심 기능

- 회사 소개 페이지  
- 프로젝트(Portfolio) 소개  
- 멤버(Team) 소개  
- 이메일 문의(Contact)  
- 채용 공고 게시 기능  
- 반응형 UI 구축  

## 기술 구현

### 서버 및 인프라

- AWS Lightsail 기반 VPS 환경 구성  
- WordPress 설치 및 기본 설정  
- 도메인 연결 및 SSL 구성  
- 백업·보안 관련 기본 환경 설정  

### 프론트엔드 / UI

- **기획 문서 기반의 페이지 구조를 Elementor로 구현**  
- 텍스트·이미지·배너·그리드 컴포넌트를 조합하여 맞춤형 레이아웃 제작  
- PC·모바일 모두 최적화된 반응형 UI 설정  
- 페이지별 섹션 흐름을 사용자 관점에서 재구성  

### 백엔드 / CMS 구성

- 관리자 사용성을 고려해 콘텐츠 분류 구조를 단순화  
- 채용 공고·프로젝트 소개 등 반복 요소는 템플릿화  
- 이메일 문의(Contact Form) 플러그인 연동  
- 불필요한 플러그인을 최소화해 속도 최적화  

## 성과

- 기획 문서 요구사항을 충실히 반영한 기업 공식 홈페이지 구축  
- Elementor 기반으로 운영자가 직접 페이지를 쉽게 수정·추가 가능  
- 별도 개발 작업 없이도 콘텐츠 업데이트 시간이 크게 단축  
- WordPress + Lightsail 조합으로 **안정성과 비용 효율성 확보**  
- 짧은 기간 내 완성도 높은 기업 사이트 구축 성공  

## 기술적 도전과 해결

회사는 비개발자 중심으로 홈페이지를 운영할 계획이었기 때문에  
“누구나 쉽게 수정 가능한 구조”를 만들어야 했습니다.

이를 해결하기 위해:

- Elementor 기반의 시각적 편집 방식을 중심으로 구현  
- 주요 페이지(회사 소개, 프로젝트, 멤버 소개)를 템플릿 형태로 구성  
- 관리자 가이드를 제공하여 운영자가 텍스트·이미지를 직접 교체 가능하도록 구성  
- 플러그인 호환성을 고려해 경량 구성으로 속도 저하를 최소화  

그 결과, 개발자 도움 없이도 쉽게 유지보수할 수 있는 안정적인 기업 홈페이지를 완성했습니다.
