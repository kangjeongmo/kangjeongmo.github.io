## 프로젝트 개요

국내 펜션 검색 플랫폼의 전체 리뉴얼 프로젝트로, 
UI·UX 재설계부터 프론트엔드 아키텍처 변경까지  전면적으로 새롭게 구축한 프로젝트입니다.

디자이너 1명, 백엔드 개발자 1명, 프론트엔드 개발자 1명으로 구성된  
3인 프로젝트였으며, 저는 **React + Next.js 기반의 프론트엔드 개발을 담당(30% 기여)**했습니다.

검색 성능·지도 기반 필터링·타임특가 기능 등 핵심 기능을  
현대적인 UI/UX로 재구성하여 사용자 경험을 크게 개선했습니다.

## 핵심 기능

- 펜션 검색 플랫폼 UI 개발  
- 지역 기반 검색 기능  
- 네이버지도 API를 활용한 지도 기반 검색  
- 펜션 무비클립(홍보 영상) 재생 기능  
- 타임특가(특가 시간대 노출) UI  
- 반응형 프론트엔드 전체 개발  

## 기술 구현

### 프론트엔드 (담당 영역)

- **Next.js 13 App Router 기반 페이지 구성 및 폴더 구조 설계**  
- React + TypeScript로 재사용 가능한 UI 컴포넌트 개발  
- 지역 검색 · 지도 검색을 위한 UI/데이터 연동  
- 네이버지도 API 연동  
  - 지도 렌더링  
  - 마커 표시  
  - 지도 이동/줌에 따른 검색 범위 반영  
- 빠른 페이지 전환을 위한 Next.js Server Components + Client Components 조합  
- 반응형 디자인 & 모바일 화면 최적화  

### UX / UI 구현

- Adobe XD 기획 문서 기반으로 UI 구조 반영  
- 스켈레톤 UI를 적용해 로딩시간 체감 단축  
- 검색 결과 리스트/그리드/지도 연동형 UI 구성  
- 필터 모달, 슬라이더, 태그형 필터 등 사용자 친화적 디자인 적용  

### 서버 연동 / 상태 관리

- API 연동을 위한 fetch / Axios 기반 비동기 로직 구성  
- App Router의 서버 컴포넌트를 활용한 SSR 데이터 로딩 최적화  
- 검색 조건(지역, 지도 범위, 필터 등)을 클라이언트 상태로 관리  

## 성과

- 레거시 PHP 기반 UI를 Next.js + React로 전면 교체하여  
  **반응속도·검색속도·지도 이동 성능 대폭 개선**  
- 펜션 검색 경험(리스트/지도/검색창)의 UX가 크게 향상  
- 네이버지도 기반의 직관적인 검색 flow로  
  사용자의 검색 만족도 상승  
- 타임특가 기능 도입으로 플랫폼 내 프로모션 활용도 증가  
- Adobe XD 기반 기획 문서를 정확히 반영해  
  기획–디자인–개발 간 커뮤니케이션 효율 증가  

## 기술적 도전과 해결

대규모 펜션 데이터를 지도 기반으로 연동해야 했기 때문에  
지도 이동에 따른 **검색 범위 갱신·데이터 로딩 최적화**가 핵심 과제였습니다.

이를 해결하기 위해:

- 지도 이동 이벤트(debounce) 적용으로 불필요한 호출 최소화  
- Next.js Server Components 기반 SSR 데이터 로딩으로 초기 로딩 속도 개선  
- 리렌더링 최소화를 위해 컴포넌트 단위로 메모이제이션 적용  
- 펜션 리스트와 지도 사이의 데이터 흐름을 통합 관리하여 UI 동기화  

그 결과, 빠르고 자연스러운 지도 검색 UX를 갖춘  
현대적인 관광/숙박 검색 플랫폼을 성공적으로 구축했습니다.
