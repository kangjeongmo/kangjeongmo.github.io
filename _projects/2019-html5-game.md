## 프로젝트 개요

HTML5 기반 게임 엔진 **Phaser 3**를 활용해  
브라우저에서 실행되는 캐주얼 머지 게임을 개발했습니다.  
케이크를 생성하고, 같은 종류의 케이크를 합쳐 더 높은 레벨의 케이크로 업그레이드하며,  
완성된 케이크를 판매하는 간단한 경제 구조를 가진 게임입니다.

모바일 브라우저와 PC 둘 다 플레이 가능하도록  
반응형 게임 화면과 터치 조작을 지원했습니다.

## 핵심 기능

- 케이크 머지(같은 레벨의 케이크 합성)  
- 케이크 생성 시스템  
- 케이크 판매 기능  
- 점수 및 재화 시스템  
- 마우스/터치 입력 지원  
- 반응형 캔버스 UI  

## 기술 구현

### 게임 엔진 / 로직

- Phaser 3를 기반으로 게임 루프 및 장면(Scene) 구성  
- 케이크 오브젝트의 상태(레벨), 위치, 이동 애니메이션 구현  
- 머지 조건 판별 및 업그레이드 로직 개발  
- 게임 내 재화 증가/감소 및 판매 로직 구현  

### UI / 인터랙션

- HTML5 캔버스 기반 렌더링  
- 터치·마우스 드래그를 통한 케이크 이동  
- 케이크 슬롯 구조 설계 및 충돌 판정 처리  
- 점수·재화 표시 HUD(UI) 구현  

### 성능 및 플랫폼 대응

- 브라우저 중심 최적화 (FPS 유지·객체 관리)  
- 모바일/PC 모두 플레이 가능한 반응형 스케일링  
- 경량 리소스 적용으로 빠른 로딩 속도 유지  

## 성과

- 단기간(2개월) 내 게임 기획 → 구현 → 테스트까지 1인 개발 완성  
- 웹 브라우저 기반으로 별도 설치 없이 즉시 플레이 가능  
- Phaser 3 사용 경험 축적 및 HTML5 게임 구조 이해도 향상  
- 간단한 경제 시스템과 머지 로직 구현을 통해  
  향후 캐주얼 게임 개발 기반 기술 확보  

## 기술적 도전과 해결

머지 판정과 드래그 이동이 동시에 발생하면서  
오브젝트 충돌 및 레벨 업 타이밍 관리가 복잡했습니다.

이를 해결하기 위해:

- 케이크 오브젝트 상태를 **단일 State Manager**로 통합 관리  
- 충돌 판정 로직을 매 프레임 검사하지 않고  
  “드롭 시점 기준”으로 최적화  
- Phaser의 Scene 구조를 활용해  
  HUD · 게임 로직 · 효과를 분리해 성능 안정화  

그 결과, 가벼우면서도 머지 게임의 핵심 재미를 구현한  
HTML5 캐주얼 게임을 완성할 수 있었습니다.
