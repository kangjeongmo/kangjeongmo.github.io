## 프로젝트 개요

회사 내 채용 프로세스를 효율적으로 관리하기 위한  
**웹 기반 채용관리 시스템(Recruitment Management System)**을  
기획·개발·DB 설계까지 1인 체제로 구축했습니다.

지원자 페이지 생성부터 상태 변경, 피드백 기록,  
Google OAuth 인증 및 관리자 권한 분리까지  
실제 채용 절차 전반을 온라인으로 처리할 수 있는 구조로 개발했습니다.

## 핵심 기능

- Google OAuth 인증 기반 로그인  
- 직무별 지원자 페이지 자동 생성  
- 지원자 정보 관리(이력서, 포트폴리오, 기본정보)  
- 지원자 상태 변경(면접 예정, 보류, 합격/불합격 등)  
- 피드백 기록 기능(면접관 코멘트 저장)  
- 결과 통보 기능(이메일 또는 상태 노출)  
- 관리자 권한 구분에 따른 화면 및 기능 제어  

## 기술 구현

### 프론트엔드

- HTML5 / CSS3 / Bootstrap 4 기반 UI 구축  
- jQuery 3.4.1로 인터랙션 구현  
- 직무별 지원자 목록 및 상태 변경 UI 제공  
- 권한 레벨별로 노출되는 페이지/컴포넌트 분리  

### 백엔드

- CodeIgniter 3 기반 MVC 아키텍처  
- Google OAuth API 연동(지원자·관리자 로그인)  
- 지원자 프로세스별 상태를 관리하는 워크플로우 로직 구축  
- 상태 변경, 피드백 등록, 결과 통보 기능 등 핵심 로직 개발  
- 안전한 파일 업로드 및 저장 구조 구현(이력서/포트폴리오)  

### 데이터베이스

- MySQL 5.7 기반 채용 프로세스 관리 구조 설계  
- 직무(Job), 지원자(Applicant), 상태(Status History), 관리자(User) 테이블 구성  
- 상태 변경 히스토리를 모두 기록하여 추후 분석 가능  

### 서버 환경

- AWS EC2 환경에 PHP7 + CI3 기반 서비스 배포  
- 기본 보안 설정 및 SSH 기반 접근 권한 관리  
- Apache/Nginx 중 하나 선택하여 안정적 운영 환경 구성  

## 성과

- 기존 수작업으로 관리하던 채용 절차를 시스템화하여  
  **지원자 관리 속도 및 정확도 향상**  
- 직무별 지원자 페이지 자동 생성으로 채용 공고별 관리 편의성 증가  
- 상태 변경 및 피드백 기록 기능을 통해  
  **면접자·관리자 간 협업 효율 상승**  
- Google OAuth 도입으로 가입·로그인 절차 간소화  
- 관리자 권한 구분으로 보안 및 데이터 접근 통제 강화  

## 기술적 도전과 해결

채용 절차는 직무별로 요구 정보가 다르고,  
지원자 상태 관리와 피드백 구조도 복잡하게 이어지는 특성이 있었습니다.

이를 해결하기 위해:

- **상태(State) 및 히스토리(History)** 중심의 데이터 모델링을 도입  
- 직무별 화면을 자동 생성하는 템플릿 구조 구현  
- Google OAuth를 통해 인증 절차를 간소화하고 보안 강화  
- 상태 변경과 피드백을 모두 기록해  
  추후 분쟁·오류가 발생해도 즉시 추적 가능하도록 설계  

그 결과, 단일 개발자로서  
짧은 기간 동안 실질적인 채용 프로세스를 온라인화하는 데 성공했습니다.
