## 프로젝트 개요

펜션업체의 예약·정산·요금 관리 업무를 온라인으로 처리하는  
**펜션 예약관리 시스템 ERP** 개발 프로젝트입니다.

프로젝트는 두 가지 버전으로 나누어 진행되었습니다.

- **ERP 3.0 (2020.01 ~ 2021.01)**  
  AWS + Node.js + React 기반의 최신 구조  
- **ERP 1.5 (2021.02 ~ 2022.10)**  
  기존 PHP 시스템(CodeIgniter 4) 유지보수 및 기능 개선

기획·백엔드·프론트엔드 3인 팀으로 진행되었으며,  
저는 **프론트엔드 개발자로 전체 프로젝트의 30%를 기여**했습니다.

## 핵심 기능

- 펜션 정보 및 객실 관리  
- 예약 등록·수정·취소·조회  
- 요금표 달력(시즌별 요금 반영)  
- 정산 관리(수익/수수료 내역 확인)  
- 예약 현황 대시보드  
- 운영자·관리자 역할 분리

# ERP 3.0 (2020.01 ~ 2021.01)

### 기술 스택  
- AWS  
- Node.js  
- MySQL  
- React  
- Adobe XD 기반 기획 문서 기반 개발  

### 담당 업무 (프론트엔드)

- **React 기반 프론트엔드 컴포넌트 설계 및 화면 개발**  
- 요금표 달력 UI 개발 (일자별 요금·성수기/비성수기 표시)  
- 예약 리스트 및 상세 화면 구현  
- Axios 기반 API 연동  
- React Router 기반 라우팅  
- 공통 UI 컴포넌트 제작(폼, 테이블, 모달 등)  
- Adobe XD 기획 문서를 기반으로 UI 재구성  

### 주요 성과

- React 기반으로 기존 시스템 대비 **성능 및 유지보수성 향상**  
- 요금표 달력을 직관적으로 표시해 운영자의 편의성 증가  
- 예약 상세 정보, 달력, 정산 정보 등을 단일 화면에서 확인 가능하도록 UX 개선

### 기술 스택  
- PHP 7.4  
- CodeIgniter 4  
- MySQL  
- HTML, CSS, JavaScript, jQuery  

### 담당 업무 (프론트엔드)

- 기존 PHP 기반 시스템 유지보수 및 기능 개선  
- CodeIgniter 4 + jQuery 기반 UI 개발  
- 예약 리스트/검색/필터 기능 추가  
- 정산 화면 UI 개선  
- 펜션·객실 정보 입력 화면 정비  
- 버그 수정 및 운영 대응  

### 주요 성과

- 기존 시스템의 노후화된 UI를 개선하여 **운영자의 사용성 대폭 향상**  
- 검색·필터 기능 추가로 예약 처리 속도 개선  
- 정산 및 요금 관리 부분을 직관적 UI로 재구성하여 실무 효율 개선  
- React 기반 ERP 3.0 경험을 바탕으로 PHP 환경에서도 UI 구조를 체계화하여 안정성 증가

## 기술적 도전과 해결

ERP 3.0과 ERP 1.5는 **기술 스택 자체가 완전히 다른 두 프로젝트**였기 때문에  
운영자 경험이 일관되도록 UI 구성과 데이터 표시 방식을 통일하는 것이 중요한 과제였습니다.

이를 해결하기 위해:

- React에서 적용된 UI 구조(컴포넌트 스타일·데이터 표시 규칙)를  
  PHP/CI4 환경에서도 유사하게 재현  
- 시즌 요금·예약 상태 등 주요 비즈니스 로직을 시각적으로 일관되게 표현  
- 예약/정산 등 변경 가능성이 큰 화면은 모듈형 구조로 분리하여 유지보수 용이화  

그 결과, 서로 다른 기술 스택에서도 동일한 경험을 제공하는  
안정적인 예약·정산 관리 ERP 시스템을 구축할 수 있었습니다.
