## 📱 프로젝트 개요

웹빌더 플랫폼 **imweb(아임웹)**을 활용하여  
메인 페이지, AI 생성기 링크 연동 페이지, 어바웃, 문의, 요금제 등  
비즈니스용 웹사이트를 구축한 프로젝트입니다.

레이아웃 구성, 컴포넌트 배치, 스타일링, 기본 기능 연동까지  
전체 제작 과정을 **100% 단독으로 수행**했습니다.

---

## ⭐ 주요 기능

### 1) 메인 페이지(Main)
- Hero 섹션 + 핵심 기능 소개  
- 반응형 구성(PC/모바일 자동 최적화)  
- 브랜드 색상 기반 UI 구성  

### 2) AI 생성기 링크 연결 페이지
- 외부 AI 생성기 서비스 링크 연결  
- 버튼형 CTA(Call To Action) 디자인  
- 새창 열기/앱 이동 등 동작 방식 설정  

### 3) 어바웃(About)
- 회사/브랜드 소개 섹션  
- 비전, 팀, 서비스 설명 구성  
- 이미지/텍스트 하이라이트 블록 사용  

### 4) 문의(Contact)
- 아임웹 기본 문의 폼 활용  
- 이메일 알림 설정  
- 필요 요소만 배치한 단순한 UX  

### 5) 요금제(Pricing)
- 아임웹 가격표 위젯 활용  
- 월/연간 구독 요금 표시  
- 강조 플랜(추천 요금제) 디자인

## 🛠 핵심 기술 구현

### 1) 웹빌더 기반 UI 구성
- imweb 섹션 블록 기반 페이지 구성  
- Grid·Flex 기반 레이아웃 위젯 활용  
- 모바일/PC 자동 반응형 조정  

### 2) 디자인 커스터마이징
- 컬러 팔레트 및 타이포그래피 통일  
- 이미지 비율 조정 및 크롭 최적화  
- 텍스트·버튼·아이콘 스타일 세부 조정  

### 3) 링크 및 폼 기능
- 외부 AI 생성기 링크 연결  
- 사용자 문의 폼 구성 및 이메일 알림 세팅  
- CTA 동작 커스터마이징  

### 4) 유지보수 친화적 구조
- 섹션별 재사용 블록 구성  
- 관리자 화면에서 쉽게 수정 가능한 구조  
- 페이지 속도 개선(Image lazy-loading 자동 적용)

## 💡 해결한 기술 과제

1. **웹빌더 내 제한된 UI 요소로 디자인 완성도 확보**  
   - 커스텀 컬러·간격·구조 세팅으로 브랜드 아이덴티티 반영  

2. **외부 AI 생성기 링크의 사용성 개선**  
   - 새창 이동 및 버튼 스타일 개선으로 접근성 향상  

3. **모바일 최적화 문제 해결**  
   - 블록 간 여백 및 텍스트 크기를 디바이스별 최적화  

4. **요금제 비교 섹션의 시각적 강조**  
   - 가장 추천하는 요금제에 Highlighter 스타일 적용
