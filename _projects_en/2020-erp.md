## Project Overview

This is a **Pension Reservation Management System ERP** development project
that processes pension businesses' reservation, billing, and pricing management tasks online.

The project was conducted in two versions:

- **ERP 3.0 (2020.01 ~ 2021.01)**
  Modern structure based on AWS + Node.js + React
- **ERP 1.5 (2021.02 ~ 2022.10)**
  Maintenance and feature enhancement of existing PHP system (CodeIgniter 4)

Conducted by a 3-person team (planning, backend, frontend),
I **contributed 30% of the overall project as a frontend developer**.

## Key Features

- Pension information and room management
- Reservation registration, modification, cancellation, and inquiry
- Pricing calendar (seasonal pricing reflection)
- Billing management (revenue/commission details)
- Reservation status dashboard
- Operator/administrator role separation

## Technical Challenges and Solutions

Since ERP 3.0 and ERP 1.5 were **two projects with completely different tech stacks**,
unifying UI composition and data display methods for consistent operator experience was an important challenge.

To solve this, we:

- Reproduced UI structure applied in React (component styles, data display rules)
  similarly in PHP/CI4 environment
- Visually represented key business logic like seasonal pricing and reservation status consistently
- Separated screens with high change potential (reservations/billing) into modular structure for easier maintenance

As a result, we built a stable reservation and billing management ERP system
that provides the same experience across different tech stacks.
