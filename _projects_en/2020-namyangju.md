## Project Overview

Developed the **Namyangju Guesthouse Association Official Website** to provide integrated accommodation information in the Namyangju region,
with convenient web access to association introductions, tourist attraction guides, and community features.

A 4-person team project with 1 planner, 1 designer, 1 backend developer, and 1 frontend developer.
I was **responsible for React-based frontend development.**

Designed React component structure, implemented UI, and integrated APIs,
developing the entire user interface and contributing 25% to the project.

## Core Features

- Namyangju area pension / guesthouse information guide
- Association introduction page
- Regional tourist attraction introductions
- Community bulletin board
- Responsive UI configuration

## Technical Implementation

### Frontend (My Responsibility)

- Designed React-based screen component structure
- Implemented list/detail pages displaying regional information (pensions, tourist spots, etc.)
- API integration via Axios
- React Router-based routing configuration
- Applied responsive web design
- Styled card-type UI, list-type UI, etc. for each page
- Configured user input forms and community screens

### Backend & Infrastructure (Team Collaboration)

- Node.js-based API server construction (backend developer's responsibility)
- MySQL database design
- Deployment and operation configuration on AWS environment

## Achievements

- Unified platform for viewing regional accommodation and tourist information in one place
- Improved user experience (UX) with React-based UI configuration
- Completed information structure that both association members and visitors can easily use
- Built stable API-based structure through frontend-backend collaboration

## Technical Challenges & Solutions

UI structure design was difficult because various pension and tourist data
from Namyangju region were inconsistent in classification and format.

To solve this:

- **Modularized** list/category structure as React components
- **Defined common data interfaces** so different data types could be displayed with the same UI
- Unified structure by discussing API specifications with backend developer

As a result, implemented consistent UI/UX that efficiently displays various types of regional information.
