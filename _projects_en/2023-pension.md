## Project Overview

From 2020 to 2023, I developed and maintained approximately **50+ pension websites**.
Operated in a 2-person team consisting of 1 designer and 1 developer,
I was responsible for **100% of publishing** out of 50% total contribution.

Each website was developed within an average of 1-2 weeks,
implementing customized UI based on each pension's brand image, photography, amenities, and room information.

## Key Features

- Pension introduction pages
- Room information and detail pages
- Comprehensive reservation information pages
- Nearby tourist attractions
- Special features (BBQ, spa, etc.)
- Bulletin boards (notices/inquiries)
- Responsive publishing

## Technical Implementation

### Frontend / Publishing

- **100% responsibility for HTML/CSS/JavaScript publishing**
- jQuery-based interactions (menu, slider, modal, etc.)
- Responsive layout composition (PC/mobile)
- UI customization tailored to pension brand and design concept
- Room-specific pricing, options, and photo gallery publishing

### Backend / System Integration

- Frontend application aligned with PHP 7.4 + MySQL-based data structure
- Page composition based on CodeIgniter 4 or Gnuboard 5
- Publishing integration with CMS structures like bulletin boards and inquiry forms
- Structured data from admin panel to display consistently in UI

### Design Collaboration

- Perfectly published designs provided in Photoshop according to web standards
- Structured pension photography into galleries/sliders to enhance visual quality
- Collaborated with designer to apply styles matching each pension's brand image

## Achievements

- Stably developed and operated 50+ pension websites
- Fast execution of iterative projects with average 1-2 week development period
- Optimized delivery of pension information including reservations, rooms, attractions, and special features
- Established efficient collaboration process with designer
- Improved admin usability based on CodeIgniter/Gnuboard

## Technical Challenges and Solutions

Since each pension had different photos, information, and layouts,
establishing an efficient publishing process was the biggest challenge.

To solve this, we:

- **Templatized** repeatedly used UI components (room lists, attraction lists, etc.)
  for publishing
- Established style guide by defining common CSS structure
- Designed dynamic page structure where admin-entered data is reflected
  to be easily reusable across pensions
- Clearly distinguished common areas from individual areas during maintenance
  to ensure modification speed and stability

As a result, we established an efficient development process
that maintained consistent quality while producing multiple pension websites in a short period.
