## 📱 Project Overview

A project that built a business website using the web builder platform **imweb**, including main page, AI generator link integration page, about, contact, and pricing sections.

The entire production process from layout composition, component placement, styling, to basic feature integration was **100% independently performed**.

---

## ⭐ Key Features

### 1) Main Page
- Hero section + core feature introduction
- Responsive configuration (automatic optimization for PC/mobile)
- UI configuration based on brand colors

### 2) AI Generator Link Connection Page
- External AI generator service link connection
- Button-type CTA (Call To Action) design
- Action method settings like open in new window/app navigation

### 3) About Page
- Company/brand introduction section
- Vision, team, service description composition
- Image/text highlight block usage

### 4) Contact Page
- Utilized imweb default contact form
- Email notification setup
- Simple UX with only necessary elements

### 5) Pricing Page
- Utilized imweb price table widget
- Monthly/annual subscription pricing display
- Highlighted plan (recommended pricing) design

---

## 🛠 Core Technical Implementation

### 1) Web Builder-Based UI Configuration
- Page composition based on imweb section blocks
- Grid/Flex-based layout widget utilization
- Automatic responsive adjustment for mobile/PC

### 2) Design Customization
- Unified color palette and typography
- Image ratio adjustment and crop optimization
- Detailed adjustment of text, button, and icon styles

### 3) Link and Form Features
- External AI generator link connection
- User contact form composition and email notification setup
- CTA action customization

### 4) Maintenance-Friendly Structure
- Reusable block composition by section
- Structure easily modifiable from admin panel
- Page speed improvement (Image lazy-loading automatically applied)

---

## 💡 Resolved Technical Challenges

1. **Achieved design completeness with limited UI elements in web builder**
   - Reflected brand identity through custom color/spacing/structure settings

2. **Improved usability of external AI generator links**
   - Enhanced accessibility through new window navigation and button style improvements

3. **Resolved mobile optimization issues**
   - Optimized spacing between blocks and text size by device

4. **Visual emphasis for pricing comparison section**
   - Applied highlighter style to most recommended pricing plan
